一个极简的Chrome浏览器新标签页插件

## 使用

1. 克隆本项目到本地
2. 打开 `chrome://extensions/`
3. 右上角开启 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择本目录
5. 新建标签页即可看到效果
